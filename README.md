# Bee Schematic Lab

Веб-редактор и генератор ванильных схем Mindustry в графитово-золотой визуальной системе PSBees.

## Запуск

```bash
npm install
npm run dev
```

Проверить генерацию и бинарный формат схем:

```bash
npm test
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Возможности

- Генерация схем добычи, производства, обороны, энергетики, логистики, юнитов, логики и кампании.
- Настройка планеты (Серпуло / Эрекир), этапа игры, цели, размера, плотности и вспомогательных блоков.
- Режимы снабжения фабрик, обороны, юнит-производства и логистики: от ядра, локальный склад/буровые, дрон или гибрид.
- На Серпуло ресурс забирает настроенный разгрузчик, а юнит-доставка управляется MLOG. На Эрекире прямая выгрузка из ядра недоступна: схемы используют усиленный контейнер как буфер, канальный разгрузчик и автономный Manifold через Unit Cargo Loader / Unit Cargo Unload Point.
- Генерация заводских, оборонительных и юнит-производственных компоновок с линиями подачи и возврата, силовыми узлами, хранилищами и доступными для планеты блоками.
- Редактирование сетки: выбор, размещение перетаскиванием, удаление, поворот, масштабирование, подписи и отмена/повтор.
- Импорт файлов `.msch` и строк схем из буфера обмена; экспорт в бинарный формат Mindustry `.msch` и копирование base64-кода.
- Каталог ванильного содержимого Mindustry v146: 255 построек, 138 блоков окружения, 22 предмета, 11 жидкостей и 50 юнитов.
- Сохранение избранных схем локально в браузере.
- Проверка версии при запуске, по фокусу вкладки и периодически: сравниваются `version.json` развёрнутого сайта и последний коммит GitHub. Если новая сборка уже выложена, приложение предложит перезагрузить страницу; если обновлён только репозиторий — покажет, что ещё ожидается деплой.

Схемы создаются и обрабатываются полностью в браузере; серверная часть для редактора не требуется. Веб-приложение не может самостоятельно заменить файлы на хостинге, поэтому обновление исходников должно быть развёрнуто платформой публикации. Экспорт сериализует выбранный предмет в конфигурации разгрузчиков и точек выгрузки грузовых дронов. MLOG-программы не компилируются в бинарный код: скопируй программу из панели «MLOG / процессор» и вставь её в процессор после импорта `.msch`. Для Эрекира проверь подачу предмета к Unit Cargo Loader, питание и азот для создания Manifold.
